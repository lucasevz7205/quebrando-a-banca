# NEXO Anatomy
Read docs/nexo/SKILL_AUDIT_2026_11_24.md, docs/ascensao/README.md and src/lib/nexo/skill-adapters.js.
Start from approved concepts and claims, never invent factual quantities. Choose a physical model only when its mechanism matches the concept. Label analogy and limits; prefer charts for measured data, timelines for procedures, comparison matrices for distinctions. Derive motion and readouts from one model. Separate conceptual explanation from retrieval; hide answers before assessment and avoid decorative load. Use existing QBAsc scoped tokens. Require keyboard controls, text equivalent, reduced motion, static fallback and mobile verification. The application accepts only reviewed model IDs and claim references; no AI-generated HTML/JS/shaders in the trusted origin. Geometry audits, screenshots and browser testing are required before registering a renderer. No community-gallery publishing. Preserve the original Anatomy project and PACIFIC. Never merge or deploy without explicit authorization.
