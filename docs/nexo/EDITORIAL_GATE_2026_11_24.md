# NEXO editorial validation gate
Offline/server-only foundation. No real content approved, no app integration, no database writes.
1. Curator obtains authorized primary source and prepares exact text snapshot, digest, version and locator. Registry verification flag is trusted administrative input, not inferred by the code.
2. Candidate concept and relation supply exact excerpts and character offsets. Source scope, version, hash and exact substring must match. Offsets refer to UTF-16 JavaScript string positions in the extracted text snapshot, not PDF bytes. Original document revision and extraction method must be retained separately.
3. prepareEditorialReview emits immutable-content fingerprints (not signatures). Human/independent editorial review must verify semantic truth, direction, scope, relevance, currency, and source authority. Text match alone does not establish entailment.
4. compileEditorialGraph consumes only current decisions and authorized curator records from trusted storage. This module does not authenticate reviewers, grant permissions, store decisions, establish source trust or ensure transaction safety; a future service must do so. Never accept registry/approval arrays from a client or AI. Review changes invalidate the corresponding release. Prerequisite cycles and duplicate semantic pairs are blocked. No automatic closure facts.
5. Output version is the content-bound release digest, distinct from the draft label; future shadow bindings, assessed events and reviewed visuals must reference that digest. Old approvals are not transferable to changed source, endpoint or proposition.
6. No changes to 169-candidate inventory; no source material from Obsidian available. All tests use synthetic fixtures. The human review process, source retrieval, trusted persistence and runtime activation remain pending.
