# QUEBRANDO_A_BANCA_EXPORT

Exportação integral do Quebrando a Banca em 07/11/2026, para integração ao Base44 (React 19 + TanStack Start).

- `codigo_fonte/original/index.html` — o app inteiro, como publicado (HTML + CSS + JS puro, sem build). Fonte de verdade.
- `codigo_fonte/estilos/app.css`, `codigo_fonte/estilos/markup_shell.html`, `codigo_fonte/servicos/app.js` — extrações literais do original.
- `banco_de_dados/*.json` — 3755 documentos em 14 coleções, com `_schema_inferido.json`.
- `documentacao/` — ARQUITETURA, MODELO_DE_DADOS, REGRAS_DE_NEGOCIO, FUNCIONALIDADES, GUIA_MIGRACAO_BASE44, PENDENCIAS.
- `recursos/regras_do_projeto/` — método de estudo, regras de perguntas, modelo de mapa mental, discursiva e contexto do concurso.
- `manifest.json` — arquivos, finalidades, contagens, hashes e limitações. `_stats.json` — estatísticas de auditoria.

Nada foi alterado no artefato de origem. Dados pessoais de desempenho (respostas, rodadas, diário...) estão incluídos porque são do próprio dono do projeto e fazem parte da migração.
